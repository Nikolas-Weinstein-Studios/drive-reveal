Reveal in Drive folder

Jump from a Google Drive web page to the same folder in Explorer or Finder.

Drag this to your bookmarks bar:

Reveal in Drive folder

Clicking it here will not work — it only does something on a Drive page.

Before it works

  1. Install the local helper: run install/install_windows.ps1 or install/install_macos.sh from this repo. That registers the gdrivereveal:// handler.
  2. Open a folder in Google Drive, then click the bookmark.
  3. Firefox will ask which application should open the link. Choose the helper and tick Remember my choice, or you will be asked every time.

How it picks a target

Select exactly one file and it reveals that file. Select nothing, or several files, and it opens the folder you are currently viewing.

Items under Shared with me have no local path until you add a shortcut to My Drive. The helper says so rather than guessing.
